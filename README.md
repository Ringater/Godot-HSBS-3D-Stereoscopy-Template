# Godot-HSBS-3D-Stereoscopy-Template
(Godot 4) This is a starter you can use to enable stereoscopy for stereoscopic displays (3DTV). Needs your setup to be compatible with Side-By-Side Half or Top-And-Bottom Half to function.

I don't know if this exact project works in Godot 3


# How to Download
click the green Code dropdown button and then click Download ZIP
